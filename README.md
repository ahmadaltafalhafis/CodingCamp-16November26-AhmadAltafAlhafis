# 🧠 Personal Dashboard

A personal productivity dashboard built with vanilla HTML, CSS, and JavaScript.

🔗 **Live site:** `https://USERNAME.github.io/NAMA-REPO` *(update this after deploying)*

---

## ✨ Features

### 🌅 Greeting
- Displays your name with a time-based greeting (Good morning / afternoon / evening / night)
- Shows live current time and date

### ⏱️ Focus Timer
- 25-minute Pomodoro-style timer (customizable)
- Start, Pause, Stop, and Reset controls
- Visual progress bar

### ✅ To-Do List
- Add, edit, mark done, and delete tasks
- Filter tasks: All / Active / Done
- Sort tasks A→Z or Z→A
- Prevents duplicate tasks
- Saved in Local Storage

### 🔗 Quick Links
- Add and remove favorite website shortcuts
- Favicon auto-loaded for each link
- Saved in Local Storage
